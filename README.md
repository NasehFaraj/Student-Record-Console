# CSharp-SOLID-Architecture

A simple C# console application for managing student records.

## Overview
This project was created to practice core C# concepts while transitioning into the .NET ecosystem.

## Features
- Add a new student
- View all students
- Search for a student by ID
- Update student information
- Delete a student

## Learning Goals
This project is used to practice:
- C# syntax
- Classes and objects
- Properties and constructors
- Lists and collections
- Methods
- Basic input/output handling
- Simple project organization

## Tech Stack
- C#
- .NET 8
- Console Application
